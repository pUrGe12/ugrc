# Grading notes for the scaling test

The rules are `bench-cross/jev-pick/GRADING.md`'s (1-8) and the verdicts of `bench-llama/HANDOFF.md`. Settled while
grading this test, so every answer is judged the same way:

9. **A bare premise rejection** ("the document does not say the authors strained beyond 10%"), with nothing stating
   what the paper says instead, is partial; notes start `[bare]`. Earlier tests graded this form both ways. A rejection
   that gives the paper's contrary fact, even briefly, is correct. Where the question asks "how much" of something that
   did not happen, "no amount is given" stays correct as earlier grades of cssc-2020-F1 had it.
10. **A false hedge on a right answer** ("the document does not explicitly state X; however, it says X") is wrong, as
   earlier grades had it; notes carry `[hedge]` so the result can be recomputed with them counted as correct.
11. **A remark about the rendering** ("the complete table is not shown") beside a right, rightly labelled value is
   not a claim about the paper: correct, noted `[render]`.
12. **`[leak]`** marks an answer that gives away its form (quotes value/reading lines, mentions the condensed text).

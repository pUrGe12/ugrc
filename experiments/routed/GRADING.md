# Grading the routed test

The library test's rules apply as written (`../library/GRADING.md`, which brings in rules 1-29 and adds L1-L5), with
"the paper" read as the question's paper. Written before any answer of this test existed. The sheet shows the question,
its paper's title, the expected answer, the trap and the paper the router sent it to (the same for both arms); it does
not show which arm wrote an answer.

- **R1. Misrouted.** When the router sent a question to another paper, the verdict still depends only on the answer:
  "the document does not hold this" is wrong `[miss]` (L3), except on an absence question, where it is correct (L4);
  values taken from the routed paper are wrong `[paper]` (L1).

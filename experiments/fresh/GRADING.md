# Grading the fresh-paper test

The big-library test's rules apply as written: `../big-library/GRADING.md` (the library test's 1-29 and L1-L5, the
routed test's R1, B1-B3) and `../big-library/GRADING-settled.md` (B4-B5), with the short-question test's Q3
(`../short-route/GRADING-settled.md`: on an absence question, another paper's value named as that paper's is an aside;
offered as the answer it is wrong `[paper]`). Rule 25 stays strict: a shown result that is not the correct rounding of
its own inputs is wrong. Written before any answer of this test existed.

The sheet shows the question, its paper's title, the expected answer and the trap, and the papers the question's
prompts held, sorted (not by arm). It does not show which arm wrote an answer.

- **N1. The key is the paper's text.** These keys were written from pdftotext only. Where an answer gives a value the
  key lacks, it is checked against the paper's pdftotext (`text/<key>.txt`) before it is graded wrong.

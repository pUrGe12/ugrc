# Settled while grading the door on the winning setup

`GRADING.md` is frozen by hash with the plan, so these are kept here. Written after all 209 delivered answers were
graded blind and before `grade.py unseal`; hashed with `grades.json` in `graded.sha256`. Each was applied to every
letter alike.

- **D3. Values run together.** Some answers print two or three values with nothing between them: "5718" for 57 and
  18, "01224 W" for 0, 12 and 24 W, "25049.43" for 250 °C and 49.43. Where the run reads as one other number, the
  answer states that number: wrong. Notes say "run together" so they can be recounted. Where units or words keep the
  values apart ("8.42 percent9.48 percent12.59 percent"), the values are read as printed: right values with nothing
  false are correct (rule 2).
- **D4. A symbol or a garble in place of a value.** "D" (the symbol the paper uses for the discount rate) or "was
  Compared with the method ..." offered as the value claims no number: a non-answer, partial (rule 4). The same for a
  right "not given" followed by an unexplained value with no claim made for it ("does not answer this
  question.0.16 THz").
- **Rule 22 for "does not answer this question".** On a computation question, "the document does not answer this" or
  "does not say what the mean is" is literally true when the value must be computed: partial, as rule 22 has it.

# Grading the door on the winning setup

Written before any answer of this test existed. The fresh test's rules apply as written: `../fresh/GRADING.md` (the
big-library rules, Q3, N1) and `../fresh/GRADING-settled.md` (N2, rule 3 where the named table holds the row, rule 25
kept strict on an unasked conversion).

The sheet shows the question, its paper's title, the expected answer and the trap, then each delivered answer under a
letter, with citation marks like `[1]` removed from every answer alike. It does not show which arm wrote an answer.

- **D1. Only what reaches the user is graded.** A door arm that had no accepted answer within its turns delivered
  nothing; it has no letter and counts as not right. An accepted answer is graded on its rendered text alone, like
  any other: the pointers behind it are not looked at while grading.
- **D2. Terse is not partial.** A door answer may be one sentence. It is correct if it gives what the question asks,
  under the same rules as a longer answer.
